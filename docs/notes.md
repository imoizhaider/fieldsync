# Project Requirements Notes

Theek hai, yeh PRD mein kuch likha hua hai. PRD ka matlab Project
Requirement Document hai. Is mein sab kuch detail mein likha hua hai ke
konsa text extract karna hai, aur yeh sab kuch free hona chahiye.

Is kaam mein researcher ne aik website banani hai jo application ki
tarah kaam kar sake. Hum Progressive Web App (PWA) use kar rahe hain.

Apna mobile use karenge aur website ko direct aik app ki tarah chala
sakenge.

-   Website offline bhi kaam karegi.
-   Jaise hi internet available hoga, data automatically server ke saath
    sync ho jayega.
-   Server ke database se data wapas bhi aa jayega.
-   Puri configuration free honi chahiye.
-   Jaise Git merge mein conflicts se bachne ke liye kaam kiya jata hai,
    usi tarah data sync ke dauran conflicts ko handle karna hoga taa-ke
    data overwrite ya lose na ho.
